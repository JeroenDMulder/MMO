In these lab exercises you will gain experience with survival analysis in R. For this, you will use data from an animal experiment involving \(n = 400\) rats.

Data Description

The \(n = 400\) rats participated in an experiment, in which they had to find cheese in a labyrinth. The rats are randomly assigned to a variety of conditions:

  • time_from_last_meal: hours since the last meal (0-24)
  • previous training: how many times the rat did the same exercise in the past
  • cheese: the type of cheese (parmesan, gorgonzola, emmental, and feta)

The dataset includes various variables related to the outcome:

  • avg_speed
  • find_cheese (0 = no, 1 = yes)
  • time_to_find (censored if not found within 1 minute).

Note that time T of interest is the time it takes to find the cheese, so when we speak of “survival until time t”, we mean the event T > t.

Load the data into R using the readRDS() function:

lab5_dat <- readRDS("./data/data5.Rds")
str(lab5_dat) # Should show data.frame with 400 obs of 6 variables

Survival Analysis

To perform survival analysis in R, we make use of the survival package, which can be installed with install.packages("survival") and loaded with library(survival).

Question 1

Use the code below and look at the table presented. Explain what the survival column means, and do the calculations necessary to get the same numbers.

t <- c(2, 4, 5, 6, 8)
s <- c(1, 0, 1, 0, 1)

library(survival)
surv_fit <- survfit(Surv(t, s) ~ 1)

summary(surv_fit)
NoteAnswer

The first two lines create artifical surival data, where t represents the time at which an event happens, and s represents whether this event is censoring or the event of interest.

The line surv_fit <- survfit(Surv(t, s) ~ 1) does two things simultaneously. First, the function Surv() takes the data, and transforms it into an outcome variable that can be read by the survfit() function (which does the actual model fitting). Runnining Surv(t, s) shows that for the censored outcomes, a + sign is added to the survival time, indicating that the event is right censored.

Using this data, we can compute the survival probabilities manually:

  • Time 2: \(\frac{4}{5}\) survive, 4 persons remain after this time;
  • Time 4: one person is censored. They leaves the dataset. Survival is still \(\frac{4}{5}\), but only 3 persons remain after this time.
  • Time 5: person dies, so the survival probability is updated to \(\frac{2}{3} \times \frac{4}{5} = \frac{8}{15} = 0.5333\).
  • Time 6: one person is censored. They leaves the dataset. Survival probability remains the same, but only one person is left.
  • Time 8: Last person dies. We observed no one who survived longer than 8, so we estimate the probability of surviving longer to be 0.

Question 3

Define a new variable called long_training. This variable divides the rats into those who have had more training than the median amount of experience with this exercise, and those who had less than the median. Interpret the Kaplan-Meier plot for both groups.

NoteAnswer

You can create the new variable with:

# Create the new `long_training` variable
lab5_dat$long_training <- lab5_dat$previous_training > median(lab5_dat$previous_training)

To create the Kaplan-Meier survival curves for both groups, you can fit a survival model in which the survival time is predicted by group:

# Fit a survival model predicting to finding by training experience
fit <- survfit(
  Surv(time_to_find, find_cheese) ~ long_training,
  data = lab5_dat
)

# Plot Kaplan-Meier curves per group (indicated by different line types, lty)
plot(fit, lty = 1:2)

# Add a legend to the plot
legend("bottomleft", legend = c("short training", "long training"), lty = 1:2)

The figure indicates that survival probabilities, that is, the probability of not finding the cheese, are larger for mice with short training. Survival probabilities appear to be decreasing approximately linearly in time.

Question 4

Plot the survival function of the time it took all the mice to find cheese. When is the hazard rate the highest and the lowest?

NoteAnswer

To plot a survival function for all mice, we can use the same function, survfit(), but simply without any predictors (groups):

# Estimate a survival curve across the entire sample
fit <- survfit(Surv(time_to_find, find_cheese) ~ 1, data = lab5_dat)

# Visualize estimated survival curve
plot(fit, conf.int = F)

To estimate hazards, we need to run a Cox regression. Again, we do this without any predictors in the model such that the estimated hazard is representative for the entire sample:

# Fit a Cox proportional hazards model
reg_fit <- coxph(
  formula = Surv(time_to_find, find_cheese) ~ 1,
  data = lab5_dat
)

# Estimate the baseline hazard
baseline <- basehaz(reg_fit)

# Visualize the estimated hazard rate (i.e., combining estimates of Cox proportional hazard model and baseline hazard)
plot(baseline$time, baseline$hazard, type = "l", main = "Hazard rates")

It looks like the mice are finding cheese uniformly over the time period. The hazard rate (i.e., the slope) is lowest (i.e., most horizontal) at the beginning and highest at the end.

Question 5

Perform a log-rank test to see if mice with less than 5 hours of training have the same survival function as mice with 5 or more hours of training.

NoteAnswer

First, create a new variable indicating whether mice had more or less than 5 hours of training:

# Create indicator for less than 5 hours of training
lab5_dat$less_than_5 <- lab5_dat$previous_training < 5

Second, run a log-rank test comparing both groups on their mean survival time (i.e., time until finding the cheese):

fit <- survdiff(
  formula = Surv(time_to_find, find_cheese) ~ less_than_5,
  data = lab5_dat
)

Question 9

Does it seem like the proportional hazards assumption is fulfilled for the model in question 8?

NoteAnswer

We can test teh proportional hazards assumption using Schoenfeld residuals. In R, we can test if these residuals are independent of time with the cox.zph() function. To this end, first fit the Cox model, and then call the cox.zph() function on this object:

# Fit the Cox models
fit1 <- coxph(
  formula = Surv(time_to_find, find_cheese) ~ time_from_last_meal + previous_training + cheese,
  data = lab5_dat
)

fit2 <- coxph(
  formula = Surv(time_to_find, find_cheese) ~ previous_training < 5,
  data = lab5_dat
)

# Test if the Schoenfeld residuals (computed from the model) are independent of time
cox.zph(fit1)
                     chisq df       p

GLOBAL              19.912  5  0.0013
cox.zph(fit2)
                      chisq df     p

The null hypothesis is that there is a proportional relationship between the hazards. We see that the p-value is 0.051 so on the 0.05 significance level we would not reject.
